# North Star Bakery

Client website for Introduction to Web Development (Touchstones 2 to 5), by Thomas Ramirez.

## Pages
- `index.html` - Home: welcome, Featured Item of the Week (picture/source), what we're known for, hours and location
- `products.html` - Products: Signature Loaf figure, categories, filterable menu with saved favorites
- `about.html` - About: story, sourcing, team, Behind the Scenes video
- `contact.html` - Contact: Inquiry and Pre-Order Request form with JavaScript validation

## Files
- `css/styles.css` - shared mobile-first stylesheet (Flexbox, media queries at 768px and 1024px)
- `js/main.js` - product filter, favorites, form validation, localStorage
- `media/` - logo, product images, storefront, and video (same file names as Touchstone 2)

## Publish
GitHub repository > Settings > Pages > Deploy from a branch > `main` / root.
